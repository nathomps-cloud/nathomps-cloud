/INBOX
Google Drive / INBOX
The only folder with zero rules on the way in. Everything lands here first. The rule is on the way out — process daily, file fast, keep it empty.
⚡ The Daily INBOX Rule
Every item gets processed once per day — not ignored, not re-read, processed.
Processing means: file it, delete it, or act on it. Three options only.
Nothing stays in /INBOX longer than 48 hours.
If you don't know where to file it — create a home for it. Don't leave it in INBOX.
If /INBOX is overflowing — you've skipped processing. Stop everything. Clear it now.
A full INBOX is a sign the system is under stress. Treat it as an alert.
What goes in /INBOX
→Screenshots you haven't processed yet
→Docs received from others that need filing
→Ideas captured on the fly that need a real home
→Downloads that landed somewhere random
→Voice memo transcripts that need to become tasks or docs
✗Do NOT use as a project folder. Do NOT leave it full.
Setup checklist
Create /INBOX in Google Drive + star it

Make /INBOX your default save location on mobile
Clear anything sitting in Downloads → move to /INBOX → process it now

  • 6:45

  • 7:00–9:00

⚡ Midday block — 9:00 AM–12:00 PM
  • 9:00

  • 10:00–12:00

🌆 Afternoon block — 12:00–6:00 PM
  • 12:00

  • 1:00–5:00

  • 5:00
