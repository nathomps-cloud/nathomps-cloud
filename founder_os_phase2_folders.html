Google Drive / COMMAND
Your business nerve center. Mission-critical documents only. If it involves money, identity, or legal protection — it lives here.
💰 finances
Invoices, receipts, tax docs, Stripe exports, bank statements, P&L snapshots
/COMMAND/finances
⚖️ legal
Contracts, NDAs, LLC docs, terms of service, client agreements, IP filings
/COMMAND/legal
🔐 passwords
Bitwarden export backups only. Emergency access doc. Recovery codes.
/COMMAND/passwords
📄 important docs
IDs, insurance, school records, medical docs, anything you'd need in a crisis
/COMMAND/important docs
Operating rules
01Nothing enters /COMMAND that isn't mission-critical. If in doubt, it goes in /INBOX first.
02Finances: name files YYYY-MM-DD_description (e.g. 2026-05-01_stripe-export)
03Legal: keep both signed PDF and editable version side-by-side in same folder
04Passwords: never store actual passwords here — only recovery codes and backup references
05Monthly: do a 10-minute /COMMAND audit. Archive old. File stray docs from /INBOX.
Setup checklist
Create /COMMAND folder in Google Drive
Create 4 subfolders: finances · legal · passwords · important docs
Move existing financial docs into /COMMAND/finances
Move existing contracts/legal into /COMMAND/legal
Scan + upload any physical important docs
Star /COMMAND in Google Drive for instant access

/INBOX
Google Drive / INBOX
The only folder with zero rules on the way in. Everything lands here first. The rule is on the way out — process it daily, file it fast, keep it empty.
⚡ The Daily INBOX Rule
Every item in /INBOX gets processed once per day — not ignored, not re-read, processed.
Processing means: file it, delete it, or act on it. Three options only.
Nothing stays in /INBOX longer than 48 hours.
If you don't know where to file it yet — create a home for it. Don't leave it in INBOX.
If /INBOX is overflowing — you've skipped processing. Stop everything. Clear it now.
A full INBOX is a sign your system is under stress. It is not normal. Treat it as an alert.
What goes in /INBOX
→Screenshots you haven't processed yet
→Docs received from others that need filing
→Ideas captured on the fly that need a real home
→Downloads that landed somewhere random
→Voice memo transcripts that need to become tasks or docs
✗Do NOT put finished work here. Do NOT use it as a project folder. Do NOT leave it full.
Setup checklist
Create /INBOX folder in Google Drive
Star /INBOX — it should always be one tap away
Set a daily alarm: "Process INBOX" — 5 minutes, same time every day
Make /INBOX your default save location on mobile
Clear anything currently sitting in Downloads into /INBOX and process it
